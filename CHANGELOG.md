# Changelog

All notable changes to Tokens 4 Breakfast. Download: https://www.tokens4breakfast.app

From version 2.0 on, release notes are in the [Recent releases](README.md#recent-releases) table, the app's What's New sheet and the update feed at https://www.tokens4breakfast.app/appcast.xml. The entries below cover 1.x.

## [1.1.1] (2026-06)
- Notarized build with Sparkle auto-update.

## [1.1] (2026-06)
- **OpenRouter** support: live balance and spend.
- **Usage Insights**: tokens by project and by model, with weekly-limit context.
- Refinements to the menu bar spend display and rate-limit forecasting.

## [1.0] (2026-05)
- Initial public release: live menu bar spend, Claude Code 5-hour window timer,
  multi-provider tracking, AI subscription tracking, Focus Mode session budgets,
  per-provider budgets, CSV export, and Privacy Audit Log.
